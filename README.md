# Agency OS

The operating system for agencies and freelancers: get found, win the work, deliver, get paid, hand over. India first, ready for international agencies and clients.

This repository starts as a **build pack**: the research, product spec, design system and engineering plan that Claude Code uses to build the product, with the founder approving at each gate. The app code will grow around it.
