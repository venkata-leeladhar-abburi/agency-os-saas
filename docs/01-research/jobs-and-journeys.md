# Jobs to be done and journey maps

**Status:** hypotheses from desk research and our own agency work; validate in interviews.

## Jobs to be done

Written as: *When [situation], I want to [motivation], so I can [outcome].*

### Agency owner and freelancer
1. When a new enquiry arrives on any channel, I want it in one list with its source, so I can reply fast and nothing is lost.
2. When a lead looks serious, I want to send a professional quote and proposal in minutes, so I can win before a competitor replies.
3. When a client says yes, I want onboarding, contract and advance payment to happen without retyping, so I can start the work this week.
4. When a project starts, I want to plan it from our own proven phases, so every project runs the way we work best.
5. When the team is busy, I want to see who is doing what and what's at risk, so I can step in before a deadline slips.
6. When the client asks for a change, I want to turn it into a priced change request, so scope creep gets paid for.
7. When a milestone is done, I want the client to approve it in one place, so there is a record and no argument later.
8. When it's time to bill, I want correct invoices (GST, export, any currency) with a payment link and reminders, so I get paid on time.
9. When the project ends, I want to hand over everything in one signed package, so support calls don't follow us for months.
10. When a project goes well, I want a verified review and a case study on my profile, so the next client finds and trusts us.
11. When we learn something, I want it saved in our playbook, so the next project is easier.

### Team member and project lead
12. When I start my day, I want to see today's tasks and post my update in under a minute, so I can focus on the work.
13. When I need a client decision, I want to request approval with context, so I'm not chasing on chat.

### Client
14. When I hire an agency, I want to see how they work and what others say, so I can trust them with my money.
15. When the project is running, I want to see progress and what needs me, so I don't have to ask.
16. When I owe money, I want to pay in a couple of taps (UPI or card), so it's done.
17. When the project ends, I want every file, login and document in one place, so I can run my product.

## Journey map: agency owner (P1 Kiran), today versus with Agency OS

| Stage | Doing today (hypothesis) | Pain | Feeling | Opportunity in Agency OS |
| --- | --- | --- | --- | --- |
| 1 Get found | Instagram posts, referrals, a website nobody updates | Unpredictable leads; can't show process | Anxious | Profile with process and toolkit, verified reviews, marketplace |
| 2 Capture leads | DMs, calls, a sheet | Leads forgotten; no source data | Scattered | One pipeline with sources, reminders, form embed |
| 3 Win the work | Proposal in Docs or Canva, PDF on WhatsApp | Slow; inconsistent; no idea if it was read | Rushed | Templates, AI first draft, online proposal with view tracking and e-sign |
| 4 Onboard | Emails for logos and logins; manual invoice | Retyping; delays to kickoff | Impatient | Client record from the lead; portal invite; intake; advance link |
| 5 Plan | Ad-hoc tasks | Every project different; scope unclear | Uncertain | Phase templates, PRD from intake, approval gates |
| 6 Build | Chat threads, task tool, calls | No view of load or risk | Overloaded | Views, daily updates, workload, at-risk flags |
| 7 Review | Screenshots on WhatsApp; verbal approvals | Disputes; unpaid changes | Frustrated | Gate approvals with history; change requests become quotes |
| 8 Get paid | Manual invoices; reminder calls | Late payment; GST errors | Stressed | GST, export and multi-currency invoices; UPI links; auto-reminders |
| 9 Hand off | Drive folder, a zip, credentials in chat | Missing items; security risk; support calls | Exposed | Handoff package, vault, acceptance certificate |
| 10 Grow | Ask for a review sometimes | Reviews and referrals left to chance | Missed chances | Automatic review request, case study draft, retainer offer |

## Journey map: client (P4 Srinivas in India, P6 Mike abroad)

| Stage | Today | Pain | Opportunity |
| --- | --- | --- | --- |
| Choose an agency | Referrals (India), directories and calls (abroad) | Can't compare process; trust is a gamble | Process and toolkit on profiles; verified reviews |
| Agree | PDF proposal; signs a printout or by email | Confusing terms; IP worries (abroad) | Plain online proposal; e-sign; NDA and IP terms |
| Kick off | Sends assets on WhatsApp or email | Repeated requests | Intake questionnaire and uploads in one place |
| During | Calls asking for status | Doesn't know what's happening or what's needed | Portal home: progress, "Needs you", dues; weekly report |
| Approvals | Replies "ok" on chat | No record; surprises later | Approve or comment at each gate, on a phone |
| Payments | Bank transfer, UPI, wire | Unclear amounts; fees abroad | Clear invoices; UPI or card; download any invoice |
| Finish | Gets links and a call | Missing logins and docs | One handoff page; acceptance; support contact |

## Moments that matter most (hypothesis, to rank in research)

1. The first five minutes after sign-up: the first lead or sample project must appear quickly (activation).
2. Sending the first proposal: the "wow, this looks professional" moment.
3. The client's first portal visit from a WhatsApp or email link.
4. The first payment arriving through a link.
5. A gate approval that settles a dispute.
6. Handoff acceptance.
