# Sidebar

The app's main navigation, grouped by how each role works.

- **Top:** workspace switcher, then Search (Ctrl/Cmd+K).
- **Groups:** labelled with overlines.
- **Current item:** raised (`sidebar-active` + `shadow-sm`), with a filled violet icon.
- **Counts:** muted, or violet (`is-alert`) when something needs action.
- **Collapsing:** collapses to 64px icons on smaller screens and becomes a drawer on phones.
- **Labels** are the nouns users already use (Leads, Clients, Projects, Invoices).
