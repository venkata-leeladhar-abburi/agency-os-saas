# PipelineBoard

The leads Kanban.

- **Columns:** the agency's own stages, each showing a count and total value.
- **Cards:** name, service, value (tabular), source badge, owner avatar, and next follow-up (red when overdue).
- **Won column:** marked with the lime highlight.
- **Behaviour:** cards drag between columns, and the board scrolls sideways on small screens.
- **Accessibility:** cards are keyboard-focusable, and moves are announced.
