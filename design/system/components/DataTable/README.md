# DataTable

Lists of records.

- **Columns:** about five shown by default, with more from a column picker.
- **Header:** a `muted` row.
- **Rows:** 44px (36 when compact). Hover shows `accent`; selected rows show `brand-soft`.
- **Numbers and money** are right-aligned with tabular figures; IDs are in mono.
- **Bulk actions** appear when rows are selected.
- **Filters and sorting persist** per user.
- **In code:** TanStack Table inside the shadcn Table.
